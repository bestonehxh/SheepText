# highlight-custom-ext

Plugin for custom syntax highlight mapping by file extension.

Default mapping:
- `.txt` -> `plaintext`
- `.cfg` -> `ini`
- `.conf` -> `ini`
- `.log` -> `plaintext`

## Commands
- `Highlight: Apply Custom Extension Rules`
- `Highlight: Clear Custom Extension Rules`

## Install
1. Open `Plugins` tab in SheepText.
2. Click `Install...`
3. Select this folder: `Plugins/highlight-custom-ext`
4. Plugin reloads automatically.
