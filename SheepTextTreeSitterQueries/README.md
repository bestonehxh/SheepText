SheepText Tree-sitter query files.

Bundled path:
SheepTextTreeSitterQueries/<language>/highlights.scm

User override path:
~/Library/Application Support/SheepText/SheepTextTreeSitterQueries/<language>/highlights.scm

SheepText tries these query files first. If a query cannot compile for a grammar, SheepText automatically falls back to the grammar package's original query folder.
